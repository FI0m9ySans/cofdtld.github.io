Publish to GitHub

Push the current lexicon directly to your GitHub repo. The token is stored only in your browser — use a fine-grained token with Contents: Read and write on this repo only.

How to create a fine-grained token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token → choose "Only select repositories" → select your lexicon repo
  3. Repository permissions → Contents: Read and write
  4. Generate and copy the token (starts with github_pat_)
Data auto-saved in browser localStorage · use "Save file" to export JSON backup regularly
Browsers supporting File System Access API (Chrome / Edge) can read and write local files directly
